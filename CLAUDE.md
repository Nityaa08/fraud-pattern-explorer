# Transaction Pattern Explorer

## Project Context
A frontend-only fraud analytics dashboard for risk analysts at an online retailer. Lets analysts filter, visualize, and drill into ~900 transactions to identify fraud patterns.

## Stack
- Next.js 14 (App Router), TypeScript, Tailwind CSS, Recharts, date-fns
- No backend — data loaded from `public/transactions.json`
- Deployed to Vercel

## Key Architecture Decisions
- All state lives in `app/page.tsx` using React hooks. Filters flow down to charts/table.
- Chart clicks toggle filters (e.g., clicking a country bar filters by that country). Each chart gets data filtered by everything except its own dimension.
- Colour carries meaning: neutral greys, indigo for selection, red only for chargebacks/high risk, amber for medium risk.
- Transaction detail is a slide-out dialog panel (focus trapped, Escape closes) triggered by a table row click or Enter.
- Data is generated by `scripts/generate-data.js` and committed as static JSON (`public/transactions.json`, plus `public/planted.json` with the planted ids).

## Embedded Fraud Pattern
50 chargebacks from Brazil, Visa, Electronics, concentrated in a 2-hour window on Feb 24 02:00–04:00 UTC, with IP country mismatches (Nigeria/Russia/China). High amounts ($401–$780), clustered card range (BIN 411111, last four 70xx), from 5 email addresses (mostly proton.me). The planted ids are listed in `public/planted.json`, which the scorecard uses.

## File Structure
- `app/page.tsx` — main dashboard (client component)
- `components/charts/` — TimeSeriesChart (hourly, gap-filled), and CountryChart, PaymentMethodChart, AmountChart, all built on BreakdownBars
- `components/filters/FilterPanel.tsx` — sidebar filters
- `components/table/TransactionTable.tsx` — paginated sortable table
- `components/ui/` — Badge, RiskMeter, StatsBar, InsightsPanel (pattern cards), CaseBrief (the planted case and its scorecard), TransactionDetail (slide-out dialog)
- `lib/types.ts` — TypeScript interfaces
- `lib/data.ts` — data loading utilities
- `lib/utils.ts` — filtering, risk score/levels/signals, hourly series, amount buckets, sorting, formatting
- `lib/insights.ts` — suspicious-pattern rules; each returns the filter that shows its rows
- `lib/filterChips.ts` — active filters as removable tags
- `lib/scorecard.ts` — how well each pattern rule finds the planted rows (scored against `public/planted.json`, which the rules never see)
- `scripts/generate-data.js` — seeded test data generator (`node scripts/generate-data.js [seed]`)
- `tests/` — vitest tests (`npm test`)
